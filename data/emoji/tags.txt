# Scramble emoji tags: the hand-written layer on top of emojibase-data.
#
# Two kinds of lines.
#
#   cat <id> | <level 1-4> | <kind> | <label>
#     A connection a puzzle can ask about. Level is difficulty, the way
#     Connections colors work: 1 is the obvious group, 4 is the wordplay one.
#     Kind is what sort of tag it is: noun (what it is), adjective (what it is
#     like), descriptor (where you find it, what it has or does), or wordplay.
#
#   <emoji> <tag> <tag?> ...
#     One emoji and every connection it belongs to. A tag ending in "?" means
#     "a player could argue it fits". Maybe tags never put an emoji into a
#     group, but they do keep it out of any puzzle where it would be ambiguous.
#
# The rule that keeps puzzles fair: when an emoji is listed here, it should
# carry EVERY cat it plausibly fits, colors included. A missing tag is how a
# puzzle ends up with two right answers. Run tools/build-emoji-data.mjs after
# editing; it checks every emoji against emojibase and every cat for size.
